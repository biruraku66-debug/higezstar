# Higezstar landing

Статический лендинг на HTML/CSS/JS. Подходит для GitHub Pages.

## Запуск локально
Откройте `index.html` в браузере или запустите локальный сервер:

```bash
python -m http.server 8000
```

## Публикация на GitHub Pages
1. Создайте репозиторий.
2. Загрузите содержимое этой папки в корень ветки `main`.
3. Откройте `Settings → Pages`.
4. Выберите `Deploy from a branch`, ветку `main`, папку `/root`.

## Форма
Сейчас форма формирует письмо через `mailto:`. Для стабильной отправки без почтового приложения подключите Formspree, EmailJS или собственный backend.
