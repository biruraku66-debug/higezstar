# Higezstar landing

Статический адаптивный лендинг на HTML/CSS/JS. Подходит для GitHub Pages.

## Что внутри
- Desktop-версия сохранена.
- Для экранов до 720 px включается отдельная мобильная композиция: компактный hero, бирюзовый burger, мобильная сетка преимуществ, пазловые карточки услуг, компактная карточка тарифов, вертикальные этапы и адаптированная форма.
- Файл `.nojekyll` добавлен для прямой публикации статического сайта через GitHub Pages.

## Запуск локально
Откройте `index.html` в браузере или запустите локальный сервер:

```bash
python -m http.server 8000
```

## Публикация на GitHub Pages
1. Загрузите содержимое папки `higezstar_site` в корень ветки `main`.
2. В репозитории откройте `Settings → Pages`.
3. Выберите `Deploy from a branch`, ветку `main`, папку `/(root)`.
4. После commit GitHub Pages обновит и desktop, и mobile по одному адресу.

## Форма
Сейчас форма формирует письмо через `mailto:`. Для стабильной отправки без почтового приложения подключите Formspree, EmailJS или собственный backend.
